The VeriQ Node.js server accelerates heavy tasks (multi-user load testing, raw DNS resolution, TLS certificate socket inspection, and CORS bypass).

Default local development server runs at http://localhost:3000.

🚀 How to Run the Local Backend

In your terminal inside the repository folder, execute:

npm start

This starts the Express server on port 3000 with raw socket, TLS, DNS, and load testing APIs enabled.
